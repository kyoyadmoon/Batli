# 字學 Batli 專案規範

## 產品方向

### 1. 首頁作為主控入口

- 首頁目前固定提供三個入口：`開始學習`、`繼續學習`、`設定`
- `開始學習` 會開啟主題選單 overlay，不是直接切到另一個模組首頁
- `繼續學習` 應優先回到下一個尚未完成的生活字詞
- `設定` 為正式入口，不應再嵌回首頁內部編輯

### 2. 生活主題優先

- 生活主題識字仍是主流程
- 注音模組資料與路由保留
- 注音模組目前不作為首頁主要入口，但可以繼續維護

### 3. 課程可跳過

- 每個學習步驟都應提供明確的跳過方式
- 跳過不應造成流程卡住
- 跳過後仍應能進入下一步或下一課

## 課程設計規範

### 1. 單課內容量

- 每課新字以 2 至 3 個為原則
- 優先教高頻、生活中立刻可用的字
- 每個字都應搭配圖片、發音與情境詞
- 每個字的生活詞語需列出 2 至 6 個相關詞語
- 若內容足夠，生活詞語優先補到 6 個
- 相關詞語需搭配清楚、放大的 emoji 來輔助理解

### 2. 流程原則

- 情境導入
- 核心字學習
- 情境詞
- 理解任務
- 書寫任務（可跳過）
- 真實模擬
- 課後回顧

### 3. 書寫任務

- 不要求每個字都寫
- 只保留高價值字
- 筆順動畫作為輔助，不作為唯一學習方式

## UI / UX 規範

### 0. 視覺風格

- 整體風格以精簡、清晰為優先
- 不使用過多裝飾性元素、浮誇效果或不必要的提示文字
- 畫面應優先呈現主要任務與主要操作，不讓次要資訊搶走注意力
- 相同層級的功能應使用一致的版型、邊線與間距

### 1. 裝置優先順序

- 以 tablet 與手機為主要使用情境
- 必須支援 RWD
- 直向畫面優先設計

### 2. 版面與可讀性

- 文字要大、對比要高
- 按鈕要大且清楚
- 互動元件應避免過度密集
- 優先使用簡單的版面結構與清楚的區塊分隔
- 主要操作應集中在畫面中央與底部易觸區

### 3. 觸控目標

- 最小觸控區不得小於 `64px`
- 主要操作按鈕應優先使用更大的尺寸
- 重要按鈕之間要保留足夠間距，避免誤觸
- `寫一寫` 的練習區塊應盡量放大，優先占用主要內容寬度，讓手機與平板都容易下筆

### 4. Emoji 與圖示

- Emoji 必須能清楚表達意思
- 不可只因好看而使用含義模糊的 emoji
- 同一功能要保持一致圖示，不可在不同頁面更換
- 主要操作與固定導航按鈕應優先使用 emoji 或 icon，讓使用者一眼辨識用途
- 測驗答案選項為例外，應以純文字或純字形呈現，避免多餘圖示干擾判斷
- 若 emoji 表意不足，應補上大字標籤或更明確的視覺設計

### 5. 導航與流程

- 一個畫面只做一件事
- 不使用多層複雜選單
- 全 app 需提供一致的頂部 header
- 左上品牌 / logo 回首頁
- header 中央需顯示目前主題；若沒有目前主題則顯示 `選擇主題`
- 點擊 header 中央按鈕應開啟主題選單 overlay，而不是直接切到新頁面
- overlay 需可直接關閉，也可直接切換到任一主題
- 底部 `上一頁` / `下一步` 導航只顯示 emoji，不顯示文字，也不播放語音
- 使用者仍要能透過位置、顏色與固定版位理解下一步與跳過方式

### 6. 語音與回饋

- 每個主要操作都應有清楚回饋
- 語音引導應簡短、明確
- 語音是輔助，不是唯一資訊來源；大字標題與卡片文字可直接顯示
- `上一頁` / `下一步` 不播放語音
- `聽一聽` 題目進頁應自動播放，之後每 10 秒最多重播到第 3 次
- 音效只作為輔助，不可取代主要指引
- `聽一聽` 與 `注音測驗` 選錯時，應提供明確的視覺錯誤回饋：
  - 半透明紅色遮罩
  - `X` 動畫
  - 短暫抖動

## 內容與工程實作規範

### 1. 主題選單

- 直接從 `vocabularyModule.units` 生成
- 每個主題需有 `icon`、`title`、`voiceIntro`
- 主題按鈕需支援手機與平板下的多欄排版
- 主題卡片需有清楚的邊線，讓可點擊範圍一眼可辨識
- 主題頁預設優先使用兩欄排列；若裝置過窄再退回單欄

### 2. 跳過邏輯

- Recognition 可直接進入下一步
- Listening 可直接跳到 Writing
- Writing 可直接跳到下一字或完成單元

### 3. 設定頁

- 設定頁目前只處理輔助語言與拼音顯示
- 不顯示冗長說明文字或 `待套用` 等狀態字詞
- 儲存按鈕需根據待切換語言預覽文案
- 設定變更需長按 3 秒儲存
- 拼音開關應使用 switch 樣式，不使用一般文字按鈕

### 4. Recognition 互動

- `看一看` 頁主字卡點擊播放主字發音
- 若有輔助語言，輔助字詞卡可點擊播放對應語音
- `生活詞語` 區塊可各自播放主字音與輔助語
- 主字卡、輔助字詞卡與生活詞語應維持一致的卡片語法與間距層級
- 注音僅作為靜態輔助資訊，不設計為可點擊互動

### 5. 文件維護

- 新增主題或改變流程時，需同步更新課程提案文件
- 影響 UI 或互動原則的變更，需同步更新本規範文件

### 6. 資料來源與授權

- 台語音檔來自教育部《臺灣台語常用詞辭典》，授權為 CC BY-ND 3.0 TW
- 音檔必須保持原始檔案不修改，不可剪輯、重新編碼或混音
- 音檔放置於 `public/audio/tai/`，隨附 `LICENSE` 標示來源與授權
- 新增音檔時需確認來源為同一辭典且未經修改
- 原始下載資料（`downloads/`）不進版本控制
